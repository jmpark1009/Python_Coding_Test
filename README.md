# Python_Coding_Test

여러 코딩테스트 플랫폼에서 푸는 파이썬 알고리즘 문제를 기록하는 저장소입니다.
지금은 프로그래머스 위주로 시작하고, 추후 다른 플랫폼(리트코드 등)을 풀게 되면 최상위에 폴더를 추가해서 확장합니다.

## 목표

- 하루 1~2문제 꾸준히 풀기
- 코딩테스트에 자주 출제되는 유형(해시, 스택/큐, 힙, 정렬, 완전탐색, 탐욕법, DP, DFS/BFS, 이분탐색, 그래프) 골고루 익히기
- 매일 커밋해서 습관 만들기

## 폴더 구조

```
Python_Coding_Test/
├── README.md
├── programmers/
│   ├── 해시/
│   ├── 스택_큐/
│   ├── 힙/
│   ├── 정렬/
│   ├── 완전탐색/
│   ├── 탐욕법/
│   ├── 동적계획법/
│   ├── DFS_BFS/
│   ├── 이분탐색/
│   └── 그래프/
└── (추후 추가되는 플랫폼)
    예) baekjoon/, leetcode/ ...
```

- 플랫폼마다 최상위 폴더를 하나씩 만들고, 그 안에서 플랫폼 특성에 맞게 하위 폴더를 구성합니다.
  - `programmers/`: 코딩테스트 고득점 Kit 유형별로 구성
  - 새 플랫폼이 추가되면 해당 플랫폼 관례에 맞춰 유형별/난이도별 등으로 자유롭게 구성 (예: 백준은 문제 번호별, 난이도별 등)
- 각 유형(또는 하위) 폴더 안에는 `문제이름.py` 형식으로 저장합니다.
  예) `programmers/해시/완주하지못한선수.py`
- 풀이 파일 상단에 문제 링크와 접근 방식을 2~3줄 주석으로 남깁니다.

## 진행 현황 — programmers

> 복사용: ✅ / ⬜

| 유형 | 출제 빈도 | 문제 세트 | 진행 |
|------|:---:|:---:|:---:|
| 해시 | 높음 | 2 / 5 | ✅✅⬜⬜⬜ |
| 스택/큐 | 보통 | 2 / 6 | ✅✅⬜⬜⬜⬜ |
| 힙(Heap) | 보통 | 0 / 3 | ⬜⬜⬜ |
| 정렬 | 높음 | 3 / 3 | ✅✅✅ |
| 완전탐색 | 높음 | 1 / 7 | ✅⬜⬜⬜⬜⬜⬜ |
| 탐욕법(Greedy) | 낮음 | 0 / 6 | ⬜⬜⬜⬜⬜⬜ |
| 동적계획법(DP) | 낮음 | 0 / 5 | ⬜⬜⬜⬜⬜ |
| DFS/BFS | 높음 | 0 / 7 | ⬜⬜⬜⬜⬜⬜⬜ |
| 이분탐색 | 낮음 | 0 / 2 | ⬜⬜ |
| 그래프 | 낮음 | 0 / 3 | ⬜⬜⬜ |

예시) 해시 1문제를 풀었다면 → `해시 | 높음 | 1 / 5 | ✅⬜⬜⬜⬜`

> 새 플랫폼을 추가하면 `## 진행 현황 — 플랫폼명` 섹션을 하나 더 만들어서 같은 형식으로 관리합니다.
